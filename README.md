# Прописи БаЦзы

Тренажёр написания 22 знаков БаЦзы: 10 небесных стволов (天干) и 12 земных ветвей (地支). Рассчитан на телефон и письмо пальцем, работает без интернета.

**Открыть:** https://tiangan.ru/ (запасной адрес — https://manfred7.github.io/bazi-trainer/)

Главное — «Путь знака»: приложение само ведёт каждый знак от знакомства через обводку, полуконтур и точки к письму по памяти и в тетради. Есть столп дня, своя карта БаЦзы и цикл 60 пар. Прежние четыре режима («Знакомство», «Обводка», «По памяти», «Узнавание») остались в свободной практике. Порядок черт и чтения — по прописям школы, а не по общему стандарту. Задание — [TZ.md](TZ.md); свободная пропись без проверки запланирована после MVP.

## Установка на телефон (ярлык на главном экране)

Отдельно скачивать ничего не нужно: приложение ставится прямо с сайта. На главном экране появляется значок — красный с 天干 («небесные стволы») в строку и подписью «Прописи», — оно открывается без адресной строки, как обычное приложение, и работает без интернета.

**Android (Chrome)**
1. Откройте https://tiangan.ru/ в Chrome.
2. Внизу стартового экрана нажмите «Установить на устройство». Если кнопки нет — меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. Подтвердите — значок появится на главном экране.

**iPhone / iPad (только Safari)**
1. Откройте ссылку именно в Safari — из Chrome на iPhone приложение не устанавливается.
2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран „Домой“» → «Добавить».

**Компьютер (Chrome или Edge)**
- В адресной строке справа нажмите значок «Установить» (монитор со стрелкой) или меню → «Установить приложение». Появится ярлык в «Пуске» и на рабочем столе.

**Без интернета**
- После установки откройте приложение один раз с интернетом — дальше оно работает офлайн.
- Шрифты для подписей подгружаются при первом показе; если их ни разу не видели онлайн, без сети подписи будут системным шрифтом. Сами знаки на клетке рисуются из данных черт и от шрифтов не зависят.

**Обновления и прогресс**
- Новая версия скачивается сама. Если приложение открыто, внизу появится плашка «Вышла новая версия» — нажмите «Обновить». Приложение проверяет обновления и когда вы возвращаетесь в него из фона; закрывать и открывать заново не нужно.
- Внизу стартового экрана — «Версия от …»: дата сборки и номер коммита. Так видно, какая версия стоит на телефоне.
- Прогресс хранится на самом устройстве: у телефона и компьютера он свой. Переустановка значка прогресс не стирает, очистка данных браузера — стирает.
- «Сбросить всё» внизу стартового экрана начинает с нуля: стираются прогресс знаков, звания с историей, дни столпа и сохранённые карты. Остаются только тема и скорость анимации.
- Если поменялись иконка или название: на iPhone удалите значок и добавьте заново; Android обновит их сам (иногда в течение суток).

## Как заниматься

Главная кнопка — **«Продолжить путь»**. Приложение само решает, что делать с каждым знаком, и ведёт его по ступеням:

**Знакомство → Обводка → Полуконтур → Взгляни и напиши → По памяти → Тетрадь**

- **Обводка** — по полному бледному контуру.
- **Полуконтур** — контуром показаны только первые черты, остальные пишете сами.
- **Взгляни и напиши** — знак виден целиком 3 секунды (когда одна чистая попытка уже есть — 2), потом исчезает, и вы пишете его в пустой клетке. Пока знак на экране, писать поверх нельзя. «Ещё взглянуть» показывает его снова и считается ошибкой.
- **По памяти** — пустая клетка.
- **Тетрадь** — пишете знак на бумаге, нажимаете «Сверить», смотрите анимацию порядка черт и честно отвечаете: «Верно», «Ошибся в порядке черт» или «Не вспомнил».

На полуконтуре при ошибке мигает точка начала той черты, которую ждёт проверка.

Ступень «Точки» пока выключена: подсказки по точкам получались слишком сложными визуально, её место занял «Взгляни и напиши». Код подсказок остался в `src/components/StrokeGuide.tsx`: номера вдоль черт, изломы, подсказка «откуда и куда». Вернуть ступень можно строкой в `STAGES` (`src/logic/path.ts`).

Клетка в шагах пути занимает почти всю ширину экрана, поле между знаком и рамкой — 3%.

Под клеткой — «Черта N из M»: какую черту ждёт проверка (по памяти — только сколько написано, число черт не подсказывается). На обводке «Какая черта?» подсвечивает нужную черту без штрафа. «↺» посреди письма очищает клетку, но ошибки остаются в счёте. После того как знак написан, «↺ Ещё раз» — тренировочный круг: в прогресс идёт первая попытка.

Ступень пройдена после двух чистых попыток подряд (не больше одной ошибки), «по памяти» — после трёх. Если на знаке три ошибки и больше, он спускается на ступень ниже, а вернуться можно одним чистым проходом.

Сессия пути — 10–15 шагов. Знаки в работе идут парами подряд («написал — и сразу ещё раз»), новые знаки (не больше двух за раз и не больше четырёх в работе) — знакомство и две обводки. Задания в тетрадь стоят в конце.

**«Какая черта следующая?»** Перед письмом знака, где порядок черт уже нужно помнить (полуконтур, «взгляни и напиши», по памяти; в знаке не меньше трёх черт), идёт короткий вопрос. Знак написан до какой-то черты, нужно нажать ту, что пишется дальше, — три раза подряд. Неверная черта мигает красным, верная подсвечивается зелёным, пока её не нажмёте. На ступени это не влияет. Приложение запоминает результат и чаще спрашивает знаки, где порядок путается. За сессию — до двух таких вопросов.

**Повторения по дням.** Освоенный знак возвращается на повторение по памяти через 1, 3, 8, 20, 50, 60 дней: после верного ответа в срок интервал растёт в 2,5 раза, после ошибки сбрасывается, и знак повторяется сегодня же. Несколько верных раз за один вечер интервал не разгоняют. В сессию попадают знаки, у которых подошёл срок (не больше трёх, если есть что учить). На стартовом экране видно, сколько знаков ждут повторения сегодня.

Прогресс виден на стартовом экране: сколько знаков на каждой ступени и **печати** 22 знаков. Красная печать — знак освоен и по памяти, и в тетради; красная рамка — освоен по памяти; тушь — знак в работе.

**Звания.** Вверху стартового экрана — ваше звание, эмблема и шкала до следующего звания. Нажмите на карточку — откроется список всех званий с условиями. Когда звание повышается, приложение поздравляет (после сессии или на стартовом экране, а не посреди письма). Полученное звание не отнимается, даже если знак спустился на ступень.

| Звание | Ступеней пути | Дней столпа | Дней чистых цепочек |
|---|---|---|---|
| Новичок | — | — | — |
| Любитель | 10 | — | — |
| Адепт | 35 | 3 | — |
| Мастер | 70 | 10 | — |
| Магистр | 110 | 30 | — |
| Гранд мастер | 132 (все 22 знака освоены) | 60 (полный цикл) | 12 |

**Цепочки столпов** открываются на звании «Мастер»: четыре столпа настоящего момента (год, месяц, день, час) пишутся подряд по памяти, по чтениям. Сверху вся карта, писать — в одной большой клетке, телефон поворачивать не нужно. Цепочка чистая, если на восемь знаков не больше двух ошибок и подсказок; за день засчитывается один раз.

**Мой путь** (маленькая кнопка в правом верхнем углу карточки звания) — лента полученных званий. У каждого звания — дата и время присвоения и четыре столпа этого момента по китайскому календарю (час, день, месяц, год). Последняя строка — следующее звание и шкала до него. «Новичок» записывается при первом запуске версии со званиями.

Ступень — шаг одного знака по пути: у каждого из 22 знаков шесть ступеней, всего 132. Дни столпа — сколько дней столп дня записан в тетрадь (подряд не обязательно). Эмблемы нарисованы Codex: `scripts/gen-ranks.ps1`, затем `python scripts/build-ranks.py <папка>` → `public/ranks/*.webp`.

**Столп дня.** На стартовом экране — столпы сегодняшнего дня, месяца и года. Каждый день записывайте столп дня в тетрадь. Если оба его знака уже выучены, сначала видны только чтения: пишете по ним, потом «Сверить». Пока не выучены — просто переписываете. Приложение считает, сколько дней подряд вы записываете столп.

**Мои карты.** Введите дату и время рождения — получите четыре столпа своей карты. Путь начнёт со знаков вашей карты (это можно выключить). «Проверить себя» прячет знаки и оставляет чтения: напишите карту в тетради и сверьте. Можно добавить карты близких. Даты хранятся только на устройстве.

**Цикл 60.** Все 60 пар 甲子 … 癸亥. Пара открывается, когда оба её знака освоены по памяти. Рамкой отмечен сегодняшний день, точкой — столпы из ваших карт.

**Свободная практика** (свёрнута внизу) — прежние режимы вручную: выбираете режим и колоду. Прогресс общий с путём.

Внизу стартового экрана — **тема**: «Авто» (как в настройках телефона), «Светлая» или «Тёмная». Выбор запоминается.

### Как считаются столпы

- **День** — по календарной дате; отсчёт от 1 января 1900 года, дня 甲戌. Сутки меняются в полночь, а не в 23:00 (ранняя Крыса не учитывается).
- **Месяц и год** — по солнечным сезонам (节): год начинается с 立春, месяц меняется каждые 30° долготы Солнца. Долгота считается упрощённой формулой Миуса, точность — до 15 минут. Момент берётся в часовом поясе устройства. Если рождение близко к смене сезона, карта предупредит: месяц стоит сверить с калькулятором.
- **Час** — по местным часам, без поправки на истинное солнечное время.

Расчёт сверен с календарём на 2026 год (4 февраля 2026 — 4 февраля 2027): все 366 столпов дня и все месяцы совпали, моменты смены сезонов — с расхождением до 13,5 минуты.

## Режимы

**Знакомство.** Знак на клетке прописи, чтения (кириллица и пиньинь), стихия, инь/ян, у ветвей — животное. Порядок черт показывается анимацией:
- «Показать» — весь знак черта за чертой (при открытии карточки запускается сам);
- «Пауза» / «Дальше» — остановить и продолжить;
- «+1 черта» — по одной черте на каждое нажатие;
- скорость — медленно, обычно, быстро (запоминается).

Знаки листаются свайпом, кнопками или стрелками ← →.

**Обводка.** Бледный контур знака на клетке, пишем пальцем черту за чертой. Черта засчитывается, только если она та, что по порядку, и проведена в нужном направлении; иначе клетка коротко вспыхивает красным, а ошибка добавляется в счёт. После двух ошибок на одной черте она показывается анимацией киноварью. «Заново» — переписать знак с начала.

Обводятся все знаки колоды по порядку. В прогресс идёт первая попытка по знаку; «Заново» — для практики.

**По памяти.** Основной режим. Пустая клетка, сверху — чтение, стихия, инь/ян, у ветвей животное. Нужно написать знак целиком; проверка та же, что в обводке, но без контура. «Подсказка» показывает следующую черту и считается ошибкой. Знак засчитан, если ошибок не больше одной. После того как знак написан, можно посмотреть порядок черт анимацией.

В сессии 5, 10 или 20 знаков. Сначала выпадают знаки, которых ещё не было в сессии, дальше чаще — те, что знаешь хуже.

В конце сессии — итоги: сколько знаков засчитано, как изменилось освоение колоды, какие колоды открылись, какие знаки стоит повторить (можно повторить только их).

**Узнавание.** Выбор из четырёх вариантов, направления на выбор:
- знак → чтение;
- знак → стихия и инь/ян;
- чтение → знак;
- животное → ветвь (только земные ветви).

Неверные варианты усложняются вместе с уровнем пары: на 0–1 — случайные, на 2–3 — той же стихии (у «знак → стихия» — та же стихия с другой полярностью), на 4–5 — похожие по виду: 己 / 巳 / 已, 戊 / 戌 / 戍, 未 / 末, 辛 / 幸 (已, 戍, 末, 幸 не входят в набор — это ловушки). Верный ответ — сразу следующий вопрос; неверный — карточка знака с разбором. Ответить можно и клавишами 1–4.

## Прогресс и колоды

У каждого знака свой уровень от 0 до 5 отдельно для обводки, письма по памяти и каждого направления узнавания: засчитано — уровень растёт на 1, не засчитано — падает до 0. Знак считается освоенным с уровня 3. Прогресс хранится в браузере (localStorage).

Колоды: небесные стволы → земные ветви → все 22 знака, а также пять колод по стихиям. Следующая колода для письма по памяти открывается, когда предыдущая освоена по памяти на 80% («Открыть все» снимает ограничение). Знакомство, обводка и узнавание доступны для всех колод сразу.

## Знаки и порядок черт

Чтения, стихии и инь/ян взяты из прописей. Сверка с ТЗ и с данными порядка черт описана в [docs/stage0-pdf-review.md](docs/stage0-pdf-review.md).

Данные черт лежат в `src/data/strokes/` и собираются командой `npm run strokes` ([scripts/build-strokes.mjs](scripts/build-strokes.mjs)) из `hanzi-writer-data`. У четырёх знаков порядок черт исправлен по прописям:
- 丑 — средняя горизонталь раньше вертикали;
- 辰 — длинная откидная раньше короткой;
- 戌 — короткая горизонталь пятой;
- 癸 — 8 черт: «く» справа вверху пишется одной чертой.

## Разработка

```bash
npm install
npm run dev -- --host 127.0.0.1
```

- `npm run build` — сборка в `dist/`.
- `npm run preview -- --host 127.0.0.1` — собранная версия по адресу `/bazi-trainer/`, с service worker.
- `npm run icon` — нарисовать иконку (天干) из данных черт и сделать из неё PNG; `npm run icons` — только PNG из `public/pwa-icon.svg`.

- `npm run strokes` — пересобрать данные черт.
- `npm test` — тесты (vitest): календарь и логика пути. Запускаются и при выкладке.

Публикация: при пуше в `main` GitHub Actions (`.github/workflows/deploy.yml`) собирает проект и выкладывает его на GitHub Pages и на tiangan.ru (хостинг Beget: сборка с `BASE_PATH=/`, rsync по SSH-ключу из секрета `BEGET_SSH_KEY`).

Устройство:
- `src/data/` — знаки (`characters.ts`) и данные черт (`strokes/`, `strokes.ts`);
- `src/logic/` — прогресс (Лейтнер), путь знака: ступени и состав сессии (`path.ts`), столпы и солнечные сезоны (`calendar.ts`), карты и журнал столпа дня (`journal.ts`), обновление приложения (`update.ts`, как в «Паре вкуса»), колоды, выбор знаков для письма (`session.ts`), вопросы узнавания (`quiz.ts`), настройки;
- `src/components/` — обёртка Hanzi Writer (`useHanziWriter`), клетка письма (`WritingBoard`), плеер порядка черт (`StrokePlayer`);
- `src/screens/` — экраны режимов, старт и итоги.

Стек: Vite + React + TypeScript, [Hanzi Writer](https://github.com/chanind/hanzi-writer), vite-plugin-pwa.
