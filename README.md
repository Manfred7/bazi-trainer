# Прописи БаЦзы

Тренажёр написания 22 знаков БаЦзы: 10 небесных стволов (天干) и 12 земных ветвей (地支). Рассчитан на телефон и письмо пальцем, работает без интернета.

**Открыть:** https://manfred7.github.io/bazi-trainer/

> Готовы все четыре режима: «Знакомство», «Обводка», «По памяти» и «Узнавание». Свободная пропись — после MVP ([ТЗ](TZ.md)).

## Режимы

**Знакомство.** Знак на клетке прописи, чтения (кириллица и пиньинь), стихия, инь/ян, у ветвей — животное. Порядок черт показывается анимацией:
- «Показать» — весь знак черта за чертой (при открытии карточки запускается сам);
- «Пауза» / «Дальше» — остановить и продолжить;
- «+1 черта» — по одной черте на каждое нажатие;
- скорость — медленно, обычно, быстро (запоминается).

Знаки листаются свайпом, кнопками или стрелками ← →. Колоды: небесные стволы, земные ветви, все 22.

**Обводка.** Бледный контур знака на клетке, пишем пальцем черту за чертой. Черта засчитывается, только если она та, что по порядку, и проведена в нужном направлении; иначе клетка коротко вспыхивает красным, а ошибка добавляется в счёт. После двух ошибок на одной черте она показывается анимацией киноварью. «Заново» — переписать знак с начала.

Обводятся все знаки колоды по порядку. В прогресс идёт первая попытка по знаку; «Заново» — для практики.

**По памяти.** Основной режим. Пустая клетка, сверху — чтение, стихия, инь/ян, у ветвей животное. Нужно написать знак целиком; проверка та же, что в обводке, но без контура. «Подсказка» показывает следующую черту и считается ошибкой. Знак засчитан, если ошибок не больше одной. После того как знак написан, можно посмотреть порядок черт анимацией.

В сессии 5, 10 или 20 знаков. Сначала выпадают знаки, которых ещё не было в сессии, дальше чаще — те, что знаешь хуже.

В конце сессии — итоги: сколько знаков засчитано, как изменилось освоение колоды, какие колоды открылись, какие знаки стоит повторить (можно повторить только их).

**Узнавание.** Выбор из четырёх вариантов, направления на выбор:
- знак → чтение;
- знак → стихия и инь/ян;
- чтение → знак;
- животное → ветвь (только земные ветви).

Неверные варианты усложняются вместе с уровнем пары: на 0–1 — случайные, на 2–3 — той же стихии (у «знак → стихия» — та же стихия с другой полярностью), на 4–5 — похожие по виду: 己 / 巳 / 已, 戊 / 戌 / 戍, 未 / 末, 辛 / 幸 (已, 戍, 末, 幸 не входят в набор — это ловушки). Верный ответ — сразу следующий вопрос; неверный — карточка знака с разбором. Ответить можно и клавишами 1–4.

## Прогресс и колоды

У каждого знака свой уровень от 0 до 5 отдельно для обводки, письма по памяти и каждого направления узнавания: засчитано — уровень растёт на 1, не засчитано — падает до 0. Знак считается освоенным с уровня 3. Прогресс хранится в браузере (localStorage).

Колоды: небесные стволы → земные ветви → все 22 знака, а также пять колод по стихиям. Следующая колода для письма по памяти открывается, когда предыдущая освоена по памяти на 80% («Открыть все» снимает ограничение). Знакомство, обводка и узнавание доступны для всех колод сразу.

## Знаки и порядок черт

Чтения, стихии и инь/ян взяты из прописей. Сверка с ТЗ и с данными порядка черт описана в [docs/stage0-pdf-review.md](docs/stage0-pdf-review.md).

Данные черт лежат в `src/data/strokes/` и собираются командой `npm run strokes` ([scripts/build-strokes.mjs](scripts/build-strokes.mjs)) из `hanzi-writer-data`. У четырёх знаков порядок черт исправлен по прописям:
- 丑 — средняя горизонталь раньше вертикали;
- 辰 — длинная откидная раньше короткой;
- 戌 — короткая горизонталь пятой;
- 癸 — 8 черт: «く» справа вверху пишется одной чертой.

## Разработка

```bash
npm install
npm run dev -- --host 127.0.0.1
```

- `npm run build` — сборка в `dist/`.
- `npm run preview -- --host 127.0.0.1` — собранная версия по адресу `/bazi-trainer/`, с service worker.
- `npm run icons` — иконки из `public/pwa-icon.svg`.

Публикация: при пуше в `main` GitHub Actions собирает проект и выкладывает его на GitHub Pages (`.github/workflows/deploy.yml`).
