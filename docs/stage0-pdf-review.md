# Этап 0: разбор прописей и сверка с ТЗ

Источник: `propisi2026.pdf` — «Прописи китайских иероглифов», Центр обучения Фэн-Шуй и Ба-Цзы Сахрановой Оксаны, 2009–2026. 14 страниц A4, векторные, без текстового слоя.
Данные черт: `hanzi-writer-data@2.0.1`.

## 1. Что в прописях

| Стр. | Содержание |
|---|---|
| 1 | Обложка |
| 2–6 | Небесные стволы: по 2 знака на странице, все 10 |
| 7–12 | Земные ветви: по 2 знака на странице, все 12 |
| 13–14 | **Триграммы**: 巽 Юго-Восток 2, 艮 Северо-Восток 2, 乾 Северо-Запад 2, 坤 Юго-Запад 2 |

Триграммы в прописях — это только те 4 знака, которые входят в 24 горы (позиция «2» своего сектора). Остальных четырёх триграмм в прописях нет.

**Устройство блока знака:**
- слева подпись «Кириллица / Pinyin» (пиньинь без тонов);
- знак в двух начертаниях: кистевом (кайшу) и рубленом жирном;
- у ветвей — животное (цветом стихии);
- «Стихия Инь/Ян»;
- справа 5 рядов по 8 клеток: первый ряд показывает черты по шагам, с номером и стрелкой направления у каждой; дальше бледные контуры с номерами черт для обводки.

**Сетка:** простые квадратные клетки, **без** направляющих 田字格 / 米字格.

**Цвета стихий в прописях:** Дерево — зелёный, Огонь — красный, Земля — охра, Металл — серый, **Вода — сине-фиолетовый** (в ТЗ — тёмно-синий). Триграммы — тёмный индиго.

## 3. Порядок черт: прописи против Hanzi Writer

Число черт совпадает у 25 знаков из 26. Не совпадает только 癸: в прописях 8 черт, в Hanzi Writer — 9.

**Совпадают полностью (21):** 甲 乙 丙 丁 戊 己 庚 辛 壬 子 寅 卯 巳 午 未 申 酉 亥 巽 乾 坤.

**Расходятся (5) — нужны свои JSON поверх Hanzi Writer:**

| Знак | Прописи | Hanzi Writer | Правка (индексы черт HW с 1) |
|---|---|---|---|
| 丑 | 横折 → **横** (средняя) → **竖** → 横 | 横折 → 竖 → 横 → 横 | порядок `[1,3,2,4]` |
| 辰 | … 竖提 → **捺** (длинная) → **撇** (короткая) | … 竖提 → 撇 → 捺 | порядок `[1,2,3,4,5,7,6]` |
| 艮 | … 竖提 → **捺** → **撇** | … 竖提 → 撇 → 捺 | порядок `[1,2,3,4,6,5]` |
| 戌 | 横 → 撇 → **斜钩** → **撇** → **短横** → 点 | 横 → 撇 → 短横 → 斜钩 → 撇 → 点 | порядок `[1,2,4,5,3,6]` |

Замечание по прописям: у 申 (стр. 11) и 甲 (стр. 2) в 4-й клетке пошагового ряда уже нарисована будущая 5-я черта. Это огрех вёрстки, на порядок черт он не влияет: номер 5 стоит верно.

Для 辰 / 艮 / 戌 / 癸 порядок в прописях отличается от материкового стандарта GB, на котором построены данные Hanzi Writer. По ТЗ прописи главнее, поэтому в приложении будет порядок из прописей.
